Mọi nội dung nằm trong `content.js` — sửa file này, không cần sửa `index.html`.

- **Giờ mở cửa / Happy hour:** `hours`, `happy` → thanh trạng thái tự đổi "Đang mở / Happy hour còn…/ Đóng cửa".

- **Menu, ly chữ ký, lịch tuần, liên hệ:** `menu`, `signature`, `week`, `contact`.
